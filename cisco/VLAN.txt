Part 5: Configure trunk between switch and router
Step 19. Configure Fa0/1 as a trunk port.
interface fa0/1
switchport mode trunk
exit


Step 20. Verify trunk configuration.

You should see Fa0/1 operating in trunk mode.

Step 21. Save the switch configuration.
end

Part 6: Configure Router-on-a-Stick
Now we'll configure three subinterfaces on the router.

Step 22. Click R1 → CLI.

Step 23. Press Enter.

Step 24. Enter:

Step 25. Enter the physical interface.

exit


Step 26. Configure VLAN 10 subinterface.
interface gigabitEthernet 0/0.10
encapsulation dot1Q 10

exit


Step 27. Configure VLAN 20 subinterface.
interface gigabitEthernet 0/0.20
encapsulation dot1Q 20

Step 28. Configure VLAN 30 subinterface.
interface gigabitEthernet 0/0.30
encapsulation dot1Q 30
ip address 192.168.30.1 255.255.255.0

Step 29. Verify router configuration.
end

Expected:

Part 9: Configure ACL to block Students from Admin
Now comes the important part.

Requirement:
- Students must NOT access Admin.
- Students CAN access Faculty.
- Faculty CAN access Admin.
- Admin CAN access Faculty and Students.
We'll use an Extended ACL.

Step 44. Click R1 → CLI.

Step 45. Enter:
enable
configure terminal


Step 46. Create an extended ACL.
access-list 100 deny ip 192.168.30.0 0.0.0.255 192.168.10.0 0.0.0.255


Step 47. Permit all other traffic.
access-list 100 permit ip any any


Step 48. Apply the ACL to the Students subinterface.
interface gigabitEthernet 0/0.30
ip access-group 100 in
exit


Step 49. Exit configuration mode.
end


Step 50. Verify ACL configuration.
show access-lists


You should see:
Extended IP access list 100
    deny ip 192.168.30.0 0.0.0.255 192.168.10.0 0.0.0.255
    permit ip any any


Step 51. Verify ACL application.
show ip interface gigabitEthernet 0/0.30


Check that access list 100 is applied to inbound traffic.
ACL configured
